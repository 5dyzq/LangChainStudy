# v0.2.0 学习路线

## 版本目标

`v0.2.0` 是学习 Demo，不追求完整产品化。目标是把 `v0.1.0` 已经跑通的 Wake/Sleep 二分类实验结果交给 DeepSeek，让模型辅助完成数据解读、实验建议和工程记录风格的实验报告。

本版本完成后，应该能够：

- 调用 DeepSeek 完成简单问答。
- 从 `features.csv` 和 `metrics.json` 读取已有分析结果。
- 让 DeepSeek 根据数据摘要决定下一步应该关注哪些分析。
- 生成 Markdown 实验报告中间稿。
- 生成 `.docx` 实验报告。

## 推荐学习顺序

1. 先读 `agents/deepseek_client.py`，理解一次 LLM API 调用需要哪些参数。
2. 再读 `src/dataset_summary.py`，理解为什么不能把大体量原始数据直接丢给 LLM。
3. 再读三个 prompt 模块：`data_analysis_agent.py`、`experiment_advisor_agent.py`、`result_report_agent.py`。
4. 再读 `src/v020_report_runner.py`，看它如何把配置、数据摘要、指标、Prompt 和输出文件串起来。
5. 最后读 `src/docx_report.py`，理解“LLM 写内容”和“代码负责格式”的分工。

## 模块协作关系

```text
configs/experiment.yaml
  提供数据路径、采样率、epoch 长度、输出目录

experiments/v0.1.0_baseline/features.csv
  v0.1.0 生成的窗口级特征表

experiments/v0.1.0_baseline/metrics.json
  v0.1.0 生成的模型评估指标

src/dataset_summary.py
  把 features.csv 变成短小、结构化、可信的数据摘要

agents/data_analysis_agent.py
  基于数据摘要构造“请分析数据风险和下一步建议”的 Prompt

agents/experiment_advisor_agent.py
  基于模型指标构造“请建议下一轮实验”的 Prompt

agents/result_report_agent.py
  基于配置、数据摘要、指标、分析和建议构造报告 Prompt

agents/deepseek_client.py
  负责真正请求 DeepSeek API

src/docx_report.py
  把 Markdown 报告转成 Word 文档

src/v020_report_runner.py
  命令行入口，负责把以上模块串起来
```

## DeepSeek 直接调用和 LangChain 的区别

直接调用 API 的优点是透明：你能看到请求 URL、headers、messages 和 JSON 返回值，适合 `v0.2.0` 学基础。

LangChain 的优点是组合能力强：它可以把模型、Prompt、工具、输出解析器和多步骤流程组织成 chain 或 agent，适合 `v0.3.0` 学工具调用。

所以本项目的学习路线是：

- `v0.2.0`：直接 API，先理解 LLM 调用和报告生成。
- `v0.3.0`：LangChain，把 Python 分析函数封装成工具。
- `v0.4.0`：LangGraph，把数据分析、训练、评估、报告编排成图。

## 当前运行命令

先确保 `.env` 中存在：

```text
DEEPSEEK_API_KEY=你的 key
```

正式调用 DeepSeek：

```powershell
python -m src.v020_report_runner --config configs/experiment.yaml --question "请用一句话解释 Wake/Sleep 二分类实验的目标"
```

只验证本地文件链路：

```powershell
python -m src.v020_report_runner --config configs/experiment.yaml --question "请用一句话解释 Wake/Sleep 二分类实验的目标" --offline
```

## 完成标准

- `python -m pytest` 通过。
- `reports/v0.2.0_deepseek_experiment_report.md` 能生成。
- `reports/v0.2.0_deepseek_experiment_report.docx` 能生成。
- 报告中包含简单问答、数据摘要、DeepSeek 数据分析、DeepSeek 实验建议和实验报告正文。

## 后续进入 v0.3.0 的方向

`v0.3.0` 建议重点学习 LangChain 的三个能力：

- `PromptTemplate`：把当前手写 prompt 变成可维护模板。
- `tool calling`：把数据摘要、指标读取、图表生成封装成工具。
- `structured output`：让模型输出固定 JSON，再由代码决定怎么写报告。
