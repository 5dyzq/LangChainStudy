# 项目需求说明

## 1. 项目背景

本项目是一个探索性的 Agent 开发与机器学习工程学习项目。目标是围绕一维生理信号和睡眠监测场景，构建一个类似 AutoML 快速验证平台的原型，用于提升算法研发效率、减少重复性工作、降低算法开发门槛，并沉淀 Agent 开发经验。

第一版不追求完整通用 AutoML 平台，而是先建立一个可运行、可复现、可协作的最小闭环。

## 2. 第一版目标

第一版聚焦 50Hz 加速度信号和每 30 秒一条的 PSG 睡眠标签，完成 Wake/Sleep 二分类算法验证。

最小闭环包括：

1. 读取真实 TXT 数据。
2. 将加速度数据与 30 秒睡眠标签对齐。
3. 按标签 epoch 构造窗口样本。
4. 提取窗口级加速度特征。
5. 训练传统机器学习分类模型。
6. 输出评估指标和 Markdown 实验报告。
7. 记录版本信息与学习收获。

## 3. 数据说明

当前数据位于 `data/` 目录。

根据 `data/数据描述.docx`，数据来自 Apple Watch 加速度和 PSG 睡眠标注。当前第一版使用：

- 加速度文件：`[subject_id]_acceleration.txt`
- 睡眠标签文件：`[subject_id]_labeled_sleep.txt`

加速度文件每行格式：

```text
time_since_psg_start_seconds x_acceleration_g y_acceleration_g z_acceleration_g
```

睡眠标签文件每行格式：

```text
time_since_psg_start_seconds sleep_stage
```

睡眠标签语义：

```text
0 = Wake
1 = N1
2 = N2
3 = N3
5 = REM
```

第一版二分类映射：

```text
Wake: 0 -> 0
Sleep: 1/2/3/5 -> 1
```

## 4. 输入输出

### 输入

- 一组被试级别的加速度 TXT 文件。
- 与被试对应的睡眠标签 TXT 文件。
- 实验配置文件 `configs/experiment.yaml`。

### 输出

- 窗口级特征表。
- 模型训练结果。
- 评估指标 JSON。
- 混淆矩阵或后续图表。
- Markdown 实验报告。
- 学习记录与版本说明。

## 5. 第一版非目标

第一版暂不实现：

- 通用多模态 AutoML 平台。
- 深度学习睡眠分期模型。
- 五分类睡眠分期。
- 自动调参平台。
- Python 到 C/C++ 自动部署。
- 完整 Web UI。
- Agent 自动改代码或无限制执行代码。

这些能力放入后续阶段。

## 6. Agent 引入策略

第一版以普通 Python 程序为主，保证机器学习流水线可靠。

Agent 作为增强能力逐步引入：

1. 数据分析 Agent：解释数据规模、标签分布、异常情况。
2. 实验建议 Agent：根据结果建议特征、模型和指标。
3. 报告 Agent：将实验配置与指标整理成自然语言报告。
4. LangChain：用于 DeepSeek 调用、工具封装和结构化输出。
5. LangGraph：用于后续将完整流程编排成稳定工作流。

## 7. 协作与版本管理

项目计划上传 GitHub 与同伴协作。

推荐分支策略：

```text
main         稳定版本
dev          日常集成
feature/*    单功能开发
```

推荐版本计划：

```text
v0.1.0  纯 Python 最小闭环
v0.2.0  DeepSeek 报告 Agent
v0.3.0  LangChain 工具调用
v0.4.0  LangGraph 工作流
v1.0.0  可演示原型
```

每个版本应记录：

- 功能变化
- 实验结果
- 遇到的问题
- 学到的知识
- 下一步计划

## 8. 风险与盲区

- 标签和加速度时间戳可能存在裁剪、缺失或起止时间不完全对齐。
- 睡眠/清醒类别可能不平衡，不能只看 Accuracy。
- 以单个 30 秒 epoch 独立分类可能产生不符合睡眠结构的跳变。
- 同一被试相邻窗口高度相关，随机切分可能导致评估过于乐观。
- GitHub 不适合直接管理大体量原始 TXT 数据，建议只提交代码、说明和小样例。
